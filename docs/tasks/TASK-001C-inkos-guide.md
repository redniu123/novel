## 背景

项目已完成 InkOS 1.7.0 的非模型基线和 TASK-001B 真实模型冒烟验证，但团队尚缺少一份面向实际使用和后续二次开发的统一教程。README 展示了大量上游功能，基线和真实模型任务记录了不同层级的验证结果；这些信息需要按证据等级整合，避免把功能声明、静态实现和本地实测混为一谈。

## 目标

- 说明 InkOS 的产品定位、交互入口、核心概念和主要功能；
- 给出从项目初始化到建书、规划、写作、审查、人工审核和导出的操作教程；
- 解释故事权威状态、Markdown 投影、SQLite 记忆、模型配置和多书隔离；
- 标注每项能力的证据等级、当前限制和安全边界；
- 对照单本走量小说前 20-30 章 MVP，形成可执行的缺口矩阵和后续任务建议；
- 同时交付可维护的 Markdown 源稿和经过渲染检查的 DOCX 教程书。
