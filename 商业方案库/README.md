# 商业方案库

本目录保存基于 InkOS 二次开发项目的商业发现、市场验证和经营方案。

## 当前方案

- [BIZ-001：番茄短故事商业化生产计划](BIZ-001-番茄短故事商业化生产计划.md)

## 使用原则

1. 商业方案不是收入承诺，所有收入以实际合同、平台后台和到账记录为准。
2. 平台活动、费率和规则会变化，执行前必须重新核对官方页面和作者后台。
3. 生成小说正文、账号信息、合同、身份证明、后台截图、模型密钥、数据库、日志和运行账本不得提交 Git。
4. 故事权威状态与商业运营数据分离；所有小说和商业运行数据继续按 `book_id` 隔离。
5. 保留人工最终审核和人工发布，不自动登录或自动投稿。
6. 每个商业方向先用小样验证实际签约、实际结算和批次毛利，再决定是否工程化和扩量。
